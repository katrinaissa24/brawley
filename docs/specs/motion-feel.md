# LENS: Physical objects, not UI. Every book, page and element has mass, a hinge and a resting place; motion is what happens when the user pushes on that mass. The rules: respond in under one frame, settle with a spring, never move two things at the same speed, keep every sound under a whisper, and make the reverse of every choreography faster than the forward.

## SUMMARY
Folio's feel is built from four systems that share one vocabulary. (1) A motion token set: three easings (ease-out-expo cubic-bezier(0.16,1,0.3,1) for big arrivals, ease-out-quint cubic-bezier(0.22,1,0.36,1) for UI settles, cubic-bezier(0.5,0,0.2,1) for hinge rotations a hand would drive) and four springs (snappy k=520 c=38; gentle k=170 c=26; wobbly k=300 c=20; glue k=900 c=60 used as a 1-frame follower). Durations live on a 120/180/240/360/440/520 ms scale; everything asymmetric: out fast, back slow. (2) A shelf that is a real native horizontal scroller (OS momentum and Safari rubber-band for free) whose scrollLeft is read in rAF and written as one CSS var that drives a sticky 3D stage plus 0.35x wall parallax; books pull out on 60 ms hover intent by translateZ 56px / translateY -10px / rotateY -22deg on the snappy spring, neighbours shift 6px/2px on the gentle spring, and a crisp 2D label pill with two dots staggers in 0/40/80 ms. Detents are sensory only (no snapping to books): every spine-centre crossing the viewport centre fires a 2px spine bump and a 28 ms triangle tick, month boundaries fire a lower tock and roll the floating month pill; ticks are rate-limited to 45 ms and silenced above 2500 px/s. (3) Book choreography as a FLIP into a portal stage: press (scale .985) -> fly + face camera 420 ms ease-out-expo while the shelf recedes -> cover swings -180deg on its left hinge over 480 ms while the body shifts left half its width so the spread lands centred -> page 1 fades in at t=600 -> interactive at t=800. Close is the same in 700 ms. Pages are rigid sheets (rotateY on a spine hinge, perspective 2000px, translateZ 6px*sin(theta) lift) with a curvature gradient and an under-shadow whose intensity is mapped to sin(theta), not to time; drag maps finger travel across the spread to 0..180deg with a glue-spring follower, completes past 55deg or 250deg/s, lands on a k=260 c=26 spring with the flap sound gated on the 165deg crossing. (4) Page -> editor is a true shared element: the document DOM renders at scale 1 and is transformed down inside the book, so the FLIP zoom (440 ms ease-out-expo) is one element scaling to 1 with the transform removed at the end for crisp text. Editor drags write transforms in rAF with a 5px-in / 7px-out hysteresis magnet that eases into the dot at 0.35/frame and only reflows wrap and clicks on cell changes. All sound is synthesized from AudioContext primitives behind a master gain and soft compressor: page lift/land (band-passed noise bursts + 140->90 Hz sine thud), detent tick (2.4 kHz triangle, 28 ms), month tock (620->540 Hz sine), book thump (110->60 Hz sine + low-passed noise), snap click (1.8 kHz triangle + 320 Hz body), save chime (A5+E6 sines through a 110 ms feedback delay). Trackpad haptics are not reachable from a browser on macOS; "feel" is produced entirely by these detents and sounds, with a future Electron/Swift helper as the only path to real haptics. Sounds, detents, volume and reduced motion are independently toggleable, and prefers-reduced-motion collapses every 3D choreography into a 150 ms crossfade.

## DECISIONS
- **topic**: Motion tokens (single source of truth: src/motion/tokens.ts) | **decision**: Easings: EASE_OUT_EXPO = cubic-bezier(0.16,1,0.3,1) for large spatial arrivals (fly-to-centre, editor zoom); EASE_OUT_QUINT = cubic-bezier(0.22,1,0.36,1) for UI settles (pills, toolbars, overlays); EASE_HINGE = cubic-bezier(0.5,0,0.2,1) for anything rotating on a hinge (cover, programmatic page flips); EASE_IN_SOFT = cubic-bezier(0.4,0,1,1) only for things leaving (delete). Springs (mass 1, semi-implicit Euler at 1/120 s substeps, done when |x-target|<0.01 and |v|<0.01): snappy k=520 c=38 (zeta 0.83, settles ~320 ms, used for pull-out, drop, selection); gentle k=170 c=26 (zeta 1.0, ~420 ms, used for returns and neighbours); wobbly k=300 c=20 (zeta 0.58, one visible overshoot, stickers and undo restore); flipLand k=260 c=26 (zeta 0.81, page landing); glue k=900 c=60 (zeta 1.0, a 1-frame follower for finger-driven values). Durations: 120 (micro fades), 180 (pill/handle), 240 (toolbar/indicator), 360 (dim/recede), 440 (editor zoom), 480 (cover hinge), 520 (keyboard flip). Global MOTION.speed multiplier (1.0; holding Shift while triggering any choreography runs it at 0.25x for debugging) and MOTION.reduced flag (see reduced motion decision). | **rationale**: One vocabulary makes the whole app feel like one material. Springs where the user's hand let go of something (velocity can be carried in); bezier curves where the system is driving. Asymmetry (fast out, slow back) is the single biggest cheap contributor to 'Apple feel'.
- **topic**: Shelf geometry and idle state | **decision**: Scene: perspective 1400px, perspective-origin 50% 42%. Books are 240px tall, depth (cover width) 170px, spine width = clamp(24, 18 + pageCount*4 + round(wordCount/900), 60) px, gap 6px between books, standing on a 18px-thick plank whose front face carries engraved month labels (11px system font, ink at 35%) at each month's first book. Each book is a 6-face box (spine faces camera, front cover on +x side). Idle: no ambient animation at all; only a static per-book rotateZ jitter of +/-0.35deg and a 0-2px y-offset seeded from the entry id so the row reads as hand-placed. Spine lighting: a specular gradient whose x-position = 50% + ((bookCentreX - viewportCentreX)/viewportWidth)*30%, updated from the scroll CSS var so the sheen sweeps across spines as they pass the centre. Shadows: no filter:blur anywhere; each book has two pre-blurred radial-gradient shadow layers (contact: 0.35 alpha, 6px offset; ambient: 0.14 alpha, 18px offset) tinted with the cover colour at 30% mix. Wall and plank parallax: wall translates at 0.35x scroll, ceiling light glow at 0.15x, plank and books at 1x. Chronological left->right (oldest->newest); a dashed ghost book with a '+' sits at the far right and behaves like a real book on hover. Off-screen books (beyond +/-1.5 viewport widths) are not mounted (virtualised by scroll var). | **rationale**: A calm shelf is what makes hover and detents legible; anything idle-animating steals attention. Width from length gives the shelf information density for free (fat books were big days). Colour-tinted shadows are the cheapest realism win there is.
- **topic**: Shelf hover: pull-out and label pill | **decision**: Hover intent: pointerenter arms a 60 ms timer; pull-out only starts if the pointer is still over the book (kills flicker while sweeping across spines). Leave grace: 90 ms before the return starts, so crossing the 6px gap between two books never fully resets. Pull-out transform (spring snappy, driven by one --t var 0..1 written in rAF): translateZ(56px * t) translateY(-10px * t) rotateY(-22deg * t) — the book slides toward the camera, lifts slightly, and turns so the front cover becomes visible on the right; contact shadow scales 1 -> 1.25 and crossfades to the ambient layer (opacity 0.35 -> 0.22). On pointerdown add scale(0.985) translateZ(-4px) for the duration of the press (80 ms ease-out, released on pointerup). Return uses spring gentle (slower than the pull-out; asymmetric). Cursor: pointer over a book; default over wall/plank; grab/grabbing while mouse-dragging the shelf background. A tiny 'shff' sound (noise, bandpass 3000 Hz Q0.8, gain 0.02, attack 10 ms, decay 60 ms) plays once when the pull-out starts, gated to 120 ms. Label pill: rendered in a flat 2D overlay layer (never inside the 3D transform) positioned from the book's projected rect so text stays crisp: pill = title (13px system 500, ink) + date (11px muted, italic serif) in a 999px-radius paper capsule, padding 6px 12px, shadow 0 2px 8px rgba(0,0,0,.12); anchored 22px above the book's top edge, centred on the spine. Two connector dots between pill and book: 4px dot 6px above the book, 7px dot 14px above. Appearance starts 60 ms after the pull-out starts (so total 120 ms after hover): small dot at 0 ms, big dot at 40 ms, pill at 80 ms; each fades opacity 0->1, translateY 6->0, scale 0.92->1 over 180 ms EASE_OUT_QUINT. On leave all three fade together in 140 ms, no stagger. Keyboard focus (:focus-visible) shows the same pull-out and pill. | **rationale**: The pill is the reference's signature; staggering the dots then the pill reads as the label 'bubbling up' out of the book. Keeping it in 2D avoids the blurry-text-in-3D problem entirely.
- **topic**: Neighbours' reaction to a pull-out | **decision**: When book i pulls out (same --t var): books i-1 and i+1 get translateX(-/+6px * t) translateZ(8px * t); books i-2 and i+2 get translateX(-/+2px * t). Driven by spring gentle, not snappy, so they lag the hero book by ~60 ms and read as being nudged. When a book returns, neighbours settle back on the same spring; if the pointer moves directly to a neighbour, that neighbour's pull-out starts from its current nudged transform (no reset). Cover-colour tinted shadow on the hero book grows over the neighbours' spines (the ambient shadow layer is z-ordered above adjacent spines). | **rationale**: Books on a real shelf are packed; the ones beside the one you pull shift. The lag is what sells causality.
- **topic**: Scroll physics: native scroll with transform mapping | **decision**: The shelf is a real DOM scroller (.shelf-scroller: overflow-x auto, overflow-y hidden, overscroll-behavior-x contain, scrollbar-width none, scroll-behavior auto, height 100%). Its scrollable width = sum(book widths + gaps) + 2 * (viewportWidth/2 - lastBookWidth/2) so the first and last books can reach the centre focus line. Inside it a position:sticky; left:0; width:100vw stage holds the 3D scene. scroll events (passive) only set a number and schedule one rAF; the rAF writes --sx on the stage (transform: translate3d(calc(var(--sx) * -1px), 0, 0)), --sx on the wall at 0.35x and the glow at 0.15x, and runs detent detection. Trackpad horizontal two-finger scrolling therefore gets OS momentum, OS deceleration curve and (in Safari) OS rubber-band untouched. Mouse wheel: a non-passive wheel listener that, only when deltaMode==0 and |deltaY| > |deltaX|, preventDefaults and integrates deltaY into a target that a glide loop chases with scrollLeft += (target - scrollLeft) * 0.18 per frame (stops under 0.5px). Mouse drag on the wall/plank scrolls 1:1 with pointer capture; on release, velocity from the last 3 pointer samples decays at 0.95 per frame until < 0.5 px/frame. Keyboard: Left/Right move focus to the adjacent book and scroll it to the focus line over 240 ms EASE_OUT_QUINT (rAF-driven scrollLeft); Home/End go to the first/last book (520 ms EASE_OUT_EXPO). No snapping to books on trackpad scroll end: books are 24-60px wide and snapping fights momentum; the only settle is a 6px 'gravity' toward the nearest month boundary if the scroller stops within 6px of one (180 ms). | **rationale**: Nothing custom feels as good as the OS scroll curve on a MacBook trackpad, so we keep it and only map it. A transform-driven stage keeps the layer tree static (books never relayout) and lets parallax and detents hang off a single number.
- **topic**: Scroll detents, momentum and rubber-band feel | **decision**: Detent = a spine centre crossing the invisible focus line (viewport centre). Detected per rAF by comparing previous and current focus positions against precomputed spine centres (no per-book DOM reads). On a crossing with |velocity| < 2500 px/s: (visual) the crossed book gets a 2px translateY dip then springs back (snappy), and its sheen brightens +6% for 120 ms; (sound) tick. On a month-boundary crossing: the lower 'tock' plus the tick, and the month indicator rolls. Rate limit 45 ms between any two ticks; above 2500 px/s only month tocks fire (a fast flick sounds like a soft ratchet of months, not a machine gun). Books within +/-40px of the focus line get a 1px lift so the centre always looks slightly 'chosen'. Rubber-band: Safari is native. Chrome does not bounce, so at scrollLeft <= 0 or >= max, wheel deltas that push past the edge accumulate into --overscroll with resistance x' = x/(1 + x/80) capped at 60px; the stage translates by --overscroll and the 6 books nearest that edge lean rotateZ(2deg * overscroll/60) away from the pusher (like books tipping at the end of a shelf); on the first wheel event with zero delta (or after 80 ms of no wheel), overscroll springs back on k=300 c=24. Honesty: this is the entire 'feel' channel; there is no browser API to drive the MacBook trackpad's haptic actuator, and the settings popover says so ('Haptics require the desktop helper'). | **rationale**: Detents give the scroll a texture, like a click wheel, without ever fighting the scroll. Silence at high speed is what stops the sounds from becoming annoying.
- **topic**: Floating month/date indicator | **decision**: A capsule pill (system 13px 500, 'September 2026'; year only when it changes, shown as a second muted line) fixed at top-centre, 24px from the top. Shows when scrolling starts (first scroll event after idle) with opacity 0->1, translateY -6->0, 240 ms EASE_OUT_QUINT; hides 900 ms after the last scroll event with a 200 ms fade. Content changes with a directional roll: outgoing text translateY(-8px * dir) + opacity 0 over 140 ms, incoming from translateY(8px * dir) over 180 ms EASE_OUT_QUINT (dir = sign of velocity). The book nearest the focus line also gets its day ('Tue 3') shown in the pill's right end in muted italic serif, updated without animation. Hovering the pill reveals a minimal hairline timeline of months underneath (one dot per month, 240 ms), and clicking a dot scrolls to that month (520 ms EASE_OUT_EXPO with the month tocks muted during programmatic scrolls). | **rationale**: Users lose their place in a long row of spines; a floating date that rolls with direction gives orientation without a permanent header.
- **topic**: Opening a book: click to two-page spread (900 ms total) | **decision**: t=0 pointerdown: press state (scale .985, translateZ -4px). t=0 pointerup: sound thump('pickup'); measure the shelf book's rect (getBoundingClientRect on its spine face while its hover --t is frozen); set the shelf book visibility:hidden; mount a full-fidelity clone in a fixed 'stage' portal (perspective 1600px) positioned exactly on that rect with the same rotateY(-22deg * t). t=0-420 'fly': the clone animates (WAAPI, EASE_OUT_EXPO, 420 ms) to viewport centre, rotateY -> 0 so the front cover faces the camera, scaled so book height = min(78vh, 720px); simultaneously the shelf stage recedes: scale(.96) translateZ(-120px) 420 ms EASE_OUT_EXPO, and a solid dim overlay (ink at 45%, never a filter) fades in over 360 ms; the label pill fades in 120 ms. t=380 (fly 90% done): sound thump('open'); the cover begins rotateY 0 -> -180deg on its left edge (transform-origin 0 50%, 480 ms EASE_HINGE) while the book body translates X by -width/2 over the same 480 ms so the finished spread is centred; the cover's back face shows an endpaper (cover colour mixed 20% into paper). A shadow band on the exposed right page has opacity mapped to the cover angle (0.35 at -90deg -> 0 at -180deg), not to time. t=600-800: page 1 content (the real document DOM, contain:strict, rendered at scale 1 and transformed down) fades in over 200 ms. t=800: spread is interactive; page-edge affordances and the caption below the book (title, date) fade in over 160 ms with translateY 6->0. Double-click on a shelf book runs the same choreography at 1.3x speed and continues straight into the editor zoom on page 1. Shelf scrolling is inert while a book is open. | **rationale**: Fly then open, overlapping by 40 ms, reads as 'pick it up, then open it'. Rendering page text only after the cover is past halfway keeps the 3D frames cheap and stops text from being painted mid-rotation.
- **topic**: Closing a book (700 ms total) | **decision**: Triggers: Esc, click on the dim overlay, the close control, or Cmd+W. t=0: sound thump('close') at 0.8 gain. Cover closes over whatever spread is showing (rotateY -180 -> 0, 360 ms EASE_HINGE) while the body translates back by +width/2; page content fades out in the first 120 ms. t=280 (80 ms overlap): the closed book flies back to the shelf rect (360 ms EASE_OUT_QUINT, rotating to the shelf's rotateY(-22deg) if the pointer is still over its slot, else to 0), the dim overlay and shelf recede reverse over 300 ms. t=640: the stage clone is removed, the shelf book becomes visible, and its --t pull-out spring runs from 1 (or 0.3 if the pointer is elsewhere) back to rest on spring gentle; neighbours do a 2px bump on spring snappy and one detent tick plays (the book 'landing'). If the entry was deleted while open: no fly-back; the clone shrinks scale->0.85 and fades over 200 ms EASE_IN_SOFT, and the shelf gap closes with the books sliding on spring gentle. Autosave always runs before the close begins. | **rationale**: Closing must be faster than opening (nothing feels worse than waiting to leave). The landing tick and neighbour bump close the loop with the shelf's physics.
- **topic**: Page flipping: the curl/shading model | **decision**: A book of N pages is N/2 sheets (front face = right-hand page, back face = next left-hand page). Container .spread has perspective 2000px, perspective-origin 50% 50%, transform-style preserve-3d; each .sheet has transform-origin 0 50% (the spine), transform: translateZ(calc(6px * var(--s))) rotateY(calc(var(--theta) * -1deg)) where --theta is 0..180 and --s = sin(theta) (both written by JS in the same rAF); faces are position:absolute, backface-visibility hidden, the back face pre-rotated 180deg, each face contain:strict. Sheets are stacked with 0.4px translateZ steps to avoid z-fighting in Safari. No true mesh curl (too heavy, and text under a distorted mesh is unreadable); curvature is faked with three sin-mapped cues: (1) a gradient overlay on the moving sheet: from the spine rgba(0,0,0,0.18*s) fading by 35%, a specular highlight rgba(255,255,255,0.10*s) whose centre sits at 50% + 50%*cos(theta) so it sweeps across as the sheet turns; (2) an under-shadow element on the page beneath at the spine: width 60px*s, opacity 0.25*s, black-to-transparent to the right (mirrored when flipping backward); (3) the 6px*s lift so the sheet clears the stack. Left-hand flips are the same mirrored (origin 100% 50%, positive rotation). Sheet thickness: the closed-side page block shows a 1px-per-4-pages stack edge (paper #f4f1ea lines) so a thick entry looks thick. During any flip the two affected faces get will-change: transform; it is removed 100 ms after the flip ends. | **rationale**: Rigid rotation plus angle-mapped shading gives 90% of the 'real page' read at 5% of the cost, and keeps text crisp on the resting page. Mapping shade to angle rather than time means a half-dragged page is always lit correctly.
- **topic**: Page flipping: drag, click, keyboard, thresholds, sound timing | **decision**: Hit zones: the outer 12% of each page (min 44px, extended 24px beyond the page edge) is the flip zone; hovering it 'peeks' the sheet to theta=6deg over 180 ms EASE_OUT_QUINT and shows a custom 24x24 curled-corner cursor (SVG data URI, hotspot 12 12, fallback pointer). Click in the flip zone: programmatic flip 520 ms EASE_HINGE (with --s tracking). Click in the inner 88% of a page: opens the editor for that page (the brief's 'click the page to open bigger'). Drag: pointerdown in the flip zone takes pointer capture and adds .is-dragging; theta_raw = clamp((x0 - x) / spreadWidth * 180 * dir, 0, 180); the written theta chases theta_raw through the glue spring (k=900 c=60, effectively one frame of softness so the sheet feels like paper, not a rigid slider); the finger can also move vertically freely (ignored). A half-dragged page therefore hangs wherever the finger stops, correctly shaded, with the under-shadow widest near 90deg. Release: velocity = (theta_last - theta_first)/dt over the last 3 samples; complete if theta > 55deg OR v > 250 deg/s toward completion; cancel if theta < 55 and v < 250 (or v negative). Completion runs spring flipLand (k=260 c=26) from the current theta and velocity to 180; cancel runs spring gentle back to 0. Flip sound timing is tied to angle crossings, never to time: crossing 15deg upward -> pageLift (gain 0.06); crossing 165deg upward -> pageLand (gain 0.11 + 140->90 Hz thud); crossing 15deg downward on a cancel -> pageLift at half gain ('settle'); nothing on 165 downward. Programmatic flips get lift at t=0 and land at 0.72 * duration. Keyboard: Right/Left or Space/Shift+Space flip; holding a key repeats every 160 ms with 300 ms flips and up to 3 sheets in flight (each subsequent sheet offset +2px translateZ); Home/End jump to first/last spread with a single 520 ms flip of a 'stack' (the intermediate sheets flip as one block). Page numbers appear in the outer-bottom corners at 11px muted when the pointer is over the book (160 ms fade). | **rationale**: Flip zones must be discoverable without chrome; the peek and cursor do that. Angle-gated sounds mean a slow drag sounds like a slow drag, and a fling sounds like a fling.
- **topic**: Page -> editor zoom and back (shared element FLIP) | **decision**: Architecture that makes this a true shared element: the document component renders at its editor size (content width 720px + 48px padding = 768px, page height = width * 1.35) exactly once; inside the book it is displayed through transform: scale(pageW/768) on a wrapper (transform-origin 0 0), so book pages and the editor are the same DOM at different scales and text is always rasterised at scale 1. Zoom in: on click, measure the page face rect (theta must be 0; the measurement is taken from the face element inside the spread, which is flat when at rest); promote that page's wrapper to a fixed-position 'lift' layer with position:fixed at the target editor rect (centred, width min(768px, 92vw), top max(48px, (vh - pageH)/2), page scrolls internally if taller than the viewport); run FLIP: from transform translate(dx,dy) scale(pageW/768) to none, 440 ms EASE_OUT_EXPO via WAAPI with will-change:transform; on finish remove the transform and will-change so text snaps to whole pixels. Concurrently: the book behind scales 0.96 and translateY 8px (360 ms), the dim overlay deepens to 60% (320 ms), page chrome hides in 120 ms, the dotted grid fades in 0 -> 0.6 between t=300 and t=460, the editor toolbar and title/date header slide in at t=380 (translateY -6 -> 0, 200 ms). Focus/caret is set at t=440 (never earlier, focusing mid-animation causes scroll jank) at the end of the last text block, or on the title if the page is empty. Zoom out (Esc, close, click outside): grid and toolbar fade out in 120 ms, then the FLIP runs in reverse over 380 ms EASE_HINGE (a symmetric ease reads as 'putting it back'), the book pops back to scale 1 on spring gentle, and the lift layer is returned to the sheet DOM on finish (the sheet already shows the edited content, since it is the same DOM). Page navigation inside the editor (Cmd+Left/Right): no 3D; the outgoing document slides translateX(-24px * dir) + fades over 160 ms, the incoming from translateX(24px * dir) over 240 ms EASE_OUT_QUINT; the book behind performs a silent 300 ms flip so it is on the right spread when you zoom out. | **rationale**: A shared-element zoom is the difference between 'a modal opened' and 'I leaned into the page'. Sharing the DOM removes any content swap, and rendering at scale 1 keeps serif text crisp in both places.
- **topic**: Editor: dotted grid, selection, handles | **decision**: Grid: 16px cell, 1.5px dots at ink 10% alpha (light) / #e8e6e1 at 9% (dark), rendered as a radial-gradient background-image on the page (no DOM dots); opacity 0.6 at rest in the editor, 1.0 while dragging/resizing (120 ms), 0.25 after 400 ms of continuous typing (300 ms fade), back to 0.6 when the pointer moves > 6px. Grid is never visible inside the book (opacity 0 outside the editor). Selection: click on an element (image/sticker/text block frame) draws a 1.5px accent (#c15f3c / #e08a63) rounded-4px outline appearing with scale 1.02 -> 1 and opacity 0 -> 1, 140 ms EASE_OUT_QUINT; eight handles (corners 10px circles, edge-mids 10x4 pills, paper fill, accent border) fade in with a 30 ms stagger clockwise from top-left (210 ms total). Hover on a selectable element: 1px ink-15% outline in 80 ms. Deselect (click empty paper or Esc): outline scales to 1.02 and fades in 100 ms, handles vanish without stagger. Selecting while another is selected: the outline animates its rect to the new element (FLIP, 160 ms EASE_OUT_QUINT) rather than blinking. Text blocks show their frame only while selected or hovered. | **rationale**: The grid should feel like a drafting table, present when you place things and gone when you write. A travelling selection outline is a small thing that makes the editor feel continuous.
- **topic**: Editor: drag with magnetic snap, resize | **decision**: Drag begins after 4px of pointer movement (below that it is a click). On start: pointer capture, cursor grabbing, element lifts (scale 1.015, shadow 0 8px 24px rgba(0,0,0,.14) over 140 ms), grid to 1.0, toolbar hides. Per pointermove (rAF-coalesced, no React): raw position = start + delta (1:1, no smoothing) passed through the magnet: nearest dot = round(raw/16)*16; enter snapped when distance < 5px, leave snapped only when distance > 7px (hysteresis, so the element does not chatter at the boundary); while snapped the written position eases toward the dot at 0.35/frame (~70 ms settle, so it 'clicks in' rather than teleports), while unsnapped it follows raw exactly. Alignment guides: when a snapped edge/centre aligns within 6px with another element's edge/centre or the page margins, a 1px accent hairline appears for the duration (100 ms fade in/out) and the magnet widens to 6 in / 9 out on that axis. On each snapped-cell change: (a) snap click sound only if pointer speed < 600 px/s and 60 ms have passed since the last click; (b) the wrap engine updates the float/shape-outside CSS vars for the text block (reflow happens per cell, never per frame). Drop: scale 1.015 -> 1 and shadow -> 0 on spring snappy, state committed once, toolbar returns after 120 ms; if the element is dropped at its start cell nothing plays. Resize: corner handles keep aspect for images (Shift toggles free), edge handles are free; sizes snap with the same magnet; minimum 3x3 cells (48px); a size badge ('320 x 240', 11px system muted, paper capsule) appears 60 ms into the gesture near the bottom-right corner and disappears 300 ms after release; cursors nwse/nesw/ns/ew-resize. Images being resized use object-fit cover inside the frame with no re-decoding per frame; the final size commits the crop. Dropping an image file from Finder shows a snapped ghost rect (accent dashed, 40% opacity) that follows the cursor with the same magnet before the drop. | **rationale**: Snapping should feel like a magnet, not a grid: attraction with hysteresis and a short ease-in is what makes a dot feel 'grabby'. Reflowing text per cell keeps the wrap live without ever fighting the frame budget.
- **topic**: Editor: toolbar, autosave, delete/undo, stickers | **decision**: Element toolbar: appears 60 ms after the selection settles (never during a gesture), above the selection (below if < 56px of room), opacity 0->1 and translateY 4->0 over 160 ms EASE_OUT_QUINT; contains wrap mode (Auto/Break/Behind/Front/Inline), replace, delete. Text formatting toolbar: appears 250 ms after selectionchange stops, positioned above the selection rect, same animation. Autosave: debounced 800 ms after the last change, plus immediately on blur, editor close, book close and visibilitychange; the indicator is a 6px dot in the editor header: transparent when clean; muted grey when dirty; accent pulsing opacity 0.4<->1 at 900 ms while writing to IndexedDB; ink-40% for 1200 ms on success then fades out (tooltip 'Saved just now'); if a write fails the dot turns accent solid and the tooltip says why. Save chime plays only if the editing session lasted > 3 s, the user has been idle 1.5 s (never mid-typing), and at least 20 s passed since the last chime. Delete (Backspace/Delete on a selected element or toolbar): element scales to 0.9 and fades over 160 ms EASE_IN_SOFT, a low 'whump' plays, and the text reflow that releases the wrap runs after the 160 ms so the text does not jump under a still-visible image; a toast at bottom-centre ('Image removed  Undo Cmd+Z', paper capsule, translateY 8->0 + fade 200 ms) stays 5 s or until undo. Undo (Cmd+Z / Shift+Cmd+Z, command stack where a drag or resize is one entry and typing is coalesced per 1 s pause): a restored element pops in scale 0.9 -> 1 on spring wobbly with a rising 500->700 Hz 'undo' blip. Sticker insert: lands at the cursor cell with scale 0.6 -> 1 on spring wobbly and a +/-3deg rotation settling to 0; pasted or dropped images show a snapped shimmer placeholder while decoding, then fade in 200 ms. | **rationale**: Toolbars that wait for stillness never get in the way; an autosave dot that only speaks on change is the Apple 'you never think about saving' feeling; delete must be undoable and the undo must feel like a rescue.
- **topic**: Sound architecture (src/sound/engine.ts) | **decision**: One AudioContext ({latencyHint:'interactive'}), created lazily on the first pointerdown anywhere (autoplay policy) and warmed with a 50 ms silent buffer so the first real sound has no latency; resume() on visibilitychange. ## RISKS
- **risk**: Autoplay policy: AudioContext starts suspended, so the first tick or thump is silent or delayed. | **mitigation**: Create and resume the context on the first pointerdown/keydown anywhere (not on demand), play a 50 ms silent buffer to warm it, and resume again on visibilitychange; gate all sound calls behind ctx.state === 'running'.
- **risk**: Safari 3D quirks: preserve-3d breaks under overflow:hidden or opacity < 1 on an ancestor, backface-visibility flickers, spine/cover faces z-fight. | **mitigation**: Never put overflow:hidden, opacity, filter or clip-path on a preserve-3d ancestor (dim via a sibling overlay); offset every face and every sheet by 0.4-0.5px translateZ; test each choreography in Safari 17+ before Chrome, since Chrome is the forgiving one.
- **risk**: Blurry or heavy text during 3D animation; documents repainting while a sheet rotates. | **mitigation**: Render documents at scale 1 and transform down; contain:strict on faces; will-change only during flips; fade page content in only after the cover passes 50%; remove transforms at rest so glyphs land on the pixel grid.
- **risk**: Hundreds of books with shadows and 6 faces each blow the frame budget on scroll. | **mitigation**: Virtualise books outside +/-1.5 viewport widths (mount by scroll var), no filter:blur anywhere (pre-blurred gradients), a single --sx var drives the stage so scrolling never relayouts, and detent detection uses precomputed centres, never DOM reads.
- **risk**: Sound fatigue and 'machine gun' ticks during fast scrolling or fast drags. | **mitigation**: Per-sound rate gates (45/60/80 ms), silence above 2500 px/s and 600 px/s respectively, peak gains under 0.15 with a compressor safety net, randomised timbre, separate toggles for UI and paper sounds, and no sounds for programmatic scrolls or restores.
- **risk**: Chrome has no horizontal rubber-band and mouse wheels scroll vertically. | **mitigation**: Emulated overscroll lean from wheel deltas at the edges with a spring return; vertical-to-horizontal wheel glide only for deltaMode 0 mouse events, leaving trackpad gestures native.
- **risk**: contenteditable reflow while an image is dragged (float + shape-outside) stutters or steals the caret. | **mitigation**: Reflow only on snapped-cell changes, with the float sizes set through CSS vars; the caret is blurred during element gestures and restored on drop; wrap release on delete is delayed until after the 160 ms exit.
- **risk**: FLIP measurements are wrong when the source sits inside a perspective/3D ancestor. | **mitigation**: Measure the flat face element only when theta = 0 (the peek is cancelled before measuring), measure the shelf spine with its hover --t frozen, and measure the portal clone rather than the original for the reverse trip.
- **risk**: Users expect trackpad haptics because the brief asks for 'feel'. | **mitigation**: Say it plainly in the settings popover and docs; emit a 'detent' event from the engine so a later Electron/Swift helper can perform NSHapticFeedback on the same events without app changes.
- **risk**: Reduced-motion users get a broken experience if choreographies are merely shortened. | **mitigation**: MOTION.reduced switches to dedicated crossfade paths (150 ms) rather than scaling durations; every animation helper checks the flag; sounds remain a separate preference.
- **risk**: Focusing the editor mid-zoom causes scroll jumps and jank. | **mitigation**: Set focus and caret at the end of the 440 ms zoom only, with preventScroll:true, and keep the lift layer position:fixed so the document never scrolls the page.

export const SPRINGS = {
  snappy:   { k: 520, c: 38 }, // zeta 0.83, ~320 ms
  gentle:   { k: 170, c: 26 }, // zeta 1.0, ~420 ms
  wobbly:   { k: 300, c: 20 }, // zeta 0.58, one overshoot
  flipLand: { k: 260, c: 26 }, // zeta 0.81, page landing
  glue:     { k: 900, c: 60 }, // zeta 1.0, 1-frame follower
};
export function animateSpring(o: { from: number; to: number; v0?: number; spring: Spring;
  onFrame: (x: number, v: number) => void; onDone?: () => void }) {
  if (MOTION.reduced) { o.onFrame(o.to, 0); o.onDone?.(); return () => {}; }
  const { k, c, m = 1 } = o.spring; let x = o.from, v = o.v0 ?? 0, last = performance.now(), raf = 0;
  const step = () => {
    const now = performance.now(); let dt = Math.min((now - last) / 1000, 0.064) / MOTION.speed; last = now;
    while (dt > 0) { const h = Math.min(dt, 1 / 120); v += ((-k * (x - o.to) - c * v) / m) * h; x += v * h; dt -= h; }
    if (Math.abs(x - o.to) < 0.01 && Math.abs(v) < 0.01) { o.onFrame(o.to, 0); o.onDone?.(); return; }
    o.onFrame(x, v); raf = requestAnimationFrame(step);
  };
  raf = requestAnimationFrame(step);
  return () => cancelAnimationFrame(raf);
}

class SoundEngine {
  ctx?: AudioContext; master!: GainNode; noise!: AudioBuffer;
  ui = true; paper = true; volume = 0.5; private last: Record<string, number> = {};
  init() { // call on first pointerdown/keydown
    if (this.ctx) { this.ctx.resume(); return; }
    const c = (this.ctx = new AudioContext({ latencyHint: 'interactive' }));
    const comp = c.createDynamicsCompressor(); comp.threshold.value = -18; comp.ratio.value = 3; comp.attack.value = 0.003; comp.release.value = 0.1;
    this.master = c.createGain(); this.master.gain.value = this.volume; this.master.connect(comp).connect(c.destination);
    const n = c.sampleRate * 2, buf = c.createBuffer(1, n, c.sampleRate), d = buf.getChannelData(0);
    for (let i = 0; i < n; i++) d[i] = Math.random() * 2 - 1; this.noise = buf;
    const warm = c.createBufferSource(); warm.buffer = buf; const g = c.createGain(); g.gain.value = 0;
    warm.connect(g).connect(this.master); warm.start(); warm.stop(c.currentTime + 0.05);
  }
  setMuted(m: boolean) { this.master?.gain.setTargetAtTime(m ? 0.0001 : this.volume, this.ctx!.currentTime, 0.01); }
  private ok(kind: 'ui' | 'paper', name: string, gapMs: number) {
    if (!this.ctx || this.ctx.state !== 'running' || !this[kind]) return false;
    const t = performance.now(); if (t - (this.last[name] ?? -1e9) < gapMs) return false; this.last[name] = t; return true;
  }
  private env(g: GainNode, t0: number, peak: number, a: number, d: number, hold = 0) {
    const p = g.gain; p.setValueAtTime(0.0001, t0); p.exponentialRampToValueAtTime(peak, t0 + a);
    p.setValueAtTime(peak, t0 + a + hold); p.exponentialRampToValueAtTime(0.0005, t0 + a + hold + d);
  }
  private rnd(v: number, pct: number) { return v * (1 + (Math.random() * 2 - 1) * pct); }
  private noiseSrc() { const s = this.ctx!.createBufferSource(); s.buffer = this.noise; s.loop = true; s.loopStart = Math.random() * 1.5; return s; }
  private osc(type: OscillatorType, f0: number, f1: number, sweepS: number, t0: number, peak: number, a: number, d: number) {
    const c = this.ctx!, o = c.createOscillator(), g = c.createGain(); o.type = type;
    o.frequency.setValueAtTime(f0, t0); if (f1 !== f0) o.frequency.exponentialRampToValueAtTime(f1, t0 + sweepS);
    o.connect(g).connect(this.master); this.env(g, t0, peak, a, d); o.start(t0); o.stop(t0 + a + d + 0.02); return g;
  }
  private burst(filters: { type: BiquadFilterType; f: number; q?: number }[], t0: number, peak: number, a: number, d: number, hold = 0, sweep?: (bp: BiquadFilter) => void) {
    const c = this.ctx!, n = this.noiseSrc(), g = c.createGain(); let node: AudioNode = n;
    filters.forEach((f, i) => { const b = c.createBiquadFilter(); b.type = f.type; b.frequency.value = this.rnd(f.f, 0.12); b.Q.value = f.q ?? 1; if (i === 0 && sweep) sweep(b); node.connect(b); node = b; });
    node.connect(g).connect(this.master); this.env(g, t0, peak, a, this.rnd(d, 0.1), hold); n.start(t0); n.stop(t0 + a + hold + d + 0.05);
  }
  pageLift(gain = 1) { if (!this.ok('paper', 'lift', 80)) return; this.burst([{ type: 'bandpass', f: 1800, q: 0.9 }], this.ctx!.currentTime, 0.06 * gain, 0.012, 0.09); }
  pageLand(gain = 1, stretch = 1) { if (!this.ok('paper', 'land', 80)) return; const t = this.ctx!.currentTime;
    this.burst([{ type: 'bandpass', f: 900, q: 1.2 }, { type: 'highpass', f: 400 }], t, 0.11 * gain, 0.006, 0.14 * stretch, 0.02,
      bp => { bp.frequency.linearRampToValueAtTime(2600, t + 0.06 * stretch); bp.frequency.exponentialRampToValueAtTime(600, t + 0.14 * stretch); });
    this.osc('sine', 140, 90, 0.06, t, 0.05 * gain, 0.004, 0.07); }
  coverOpen() { this.pageLand(0.9, 1.4); }  coverClose() { this.pageLand(0.6, 1); }
  tick(month = false) { if (!this.ok('ui', 'tick', 45)) return; const t = this.ctx!.currentTime;
    const g = this.osc('triangle', 2400, 2400, 0, t, 0.045, 0.001, 0.028); const hp = this.ctx!.createBiquadFilter(); hp.type = 'highpass'; hp.frequency.value = 1200; g.disconnect(); g.connect(hp).connect(this.master);
    this.burst([{ type: 'bandpass', f: 4000, q: 2 }], t, 0.03, 0.001, 0.012);
    if (month) this.osc('sine', 620, 540, 0.04, t, 0.07, 0.002, 0.09); }
  thump(kind: 'pickup' | 'open' | 'close') { if (!this.ok('paper', 'thump', 150)) return; const t = this.ctx!.currentTime;
    if (kind === 'pickup') { this.osc('sine', 160, 110, 0.06, t, 0.06, 0.008, 0.12); return; }
    const g = kind === 'close' ? 0.8 : 1; this.osc('sine', 110, 60, 0.12, t, 0.14 * g, 0.008, 0.22);
    this.burst([{ type: 'lowpass', f: 500, q: 0.7 }], t, 0.05 * g, 0.01, 0.12); }
  snap() { if (!this.ok('ui', 'snap', 60)) return; const t = this.ctx!.currentTime; const f = this.rnd(1800, 0.03);
    this.osc('triangle', f, f, 0, t, 0.04, 0.001, 0.018); this.osc('sine', 320, 320, 0, t, 0.03, 0.001, 0.03); }
  shff() { if (!this.ok('paper', 'shff', 120)) return; this.burst([{ type: 'bandpass', f: 3000, q: 0.8 }], this.ctx!.currentTime, 0.02, 0.01, 0.06); }
  whump() { if (!this.ok('ui', 'whump', 150)) return; this.burst([{ type: 'lowpass', f: 300 }], this.ctx!.currentTime, 0.04, 0.005, 0.1); }
  undo() { if (!this.ok('ui', 'undo', 150)) return; this.osc('sine', 500, 700, 0.06, this.ctx!.currentTime, 0.04, 0.003, 0.08); }
  chime() { if (!this.ok('ui', 'chime', 20000)) return; const c = this.ctx!, t = c.currentTime;
    const lp = c.createBiquadFilter(); lp.type = 'lowpass'; lp.frequency.value = 3000;
    const delay = c.createDelay(0.5); delay.delayTime.value = 0.11; const fb = c.createGain(); fb.gain.value = 0.25; const wet = c.createGain(); wet.gain.value = 0.15;
    delay.connect(fb).connect(delay); lp.connect(this.master); lp.connect(delay).connect(wet).connect(this.master);
    [[880, 0], [1318.5, 0.06]].forEach(([f, dt]) => { const o = c.createOscillator(), g = c.createGain(); o.type = 'sine'; o.frequency.value = f;
      o.connect(g).connect(lp); this.env(g, t + dt, 0.05, 0.01, 0.6); o.start(t + dt); o.stop(t + dt + 0.7); });
  }
}

export function bindShelf(scroller: HTMLElement, stage: HTMLElement, layout: { centers: number[]; monthStart: Set<number>; max: number }, ui: ShelfUI) {
  let sx = scroller.scrollLeft, prev = sx, prevT = performance.now(), raf = 0, idle = 0, over = 0, overRaf = 0;
  const half = () => scroller.clientWidth / 2;
  const frame = () => {
    raf = 0; const now = performance.now(); const dt = Math.max(1, now - prevT); const vel = ((sx - prev) / dt) * 1000; // px/s
    stage.style.setProperty('--sx', String(sx));            // stage: translate3d(calc(var(--sx) * -1px + var(--over, 0) * 1px), 0, 0); wall uses -0.35px, glow -0.15px
    const f0 = prev + half(), f1 = sx + half(), lo = Math.min(f0, f1), hi = Math.max(f0, f1);
    if (ui.detents && f0 !== f1) for (let i = 0; i < layout.centers.length; i++) {
      const cx = layout.centers[i]; if (cx <= lo || cx > hi) continue;
      const month = layout.monthStart.has(i);
      if (Math.abs(vel) < 2500 || month) { sound.tick(month); ui.bump(i); }  // 2px dip on spring snappy, +6% sheen 120ms
    }
    ui.indicator(f1, Math.sign(vel)); prev = sx; prevT = now;
  };

  // Mouse wheel (vertical) -> horizontal glide. Trackpad horizontal stays native.
  let target = sx, gliding = false;
  scroller.addEventListener('wheel', (e) => {
    const atEdge = (scroller.scrollLeft <= 0 && e.deltaX < 0) || (scroller.scrollLeft >= layout.max && e.deltaX > 0);

export const CELL = 16;
export type Magnet = { snapped: boolean; x: number; y: number; cellX: number; cellY: number; inR: number; outR: number };
export const newMagnet = (x: number, y: number): Magnet => ({ snapped: false, x, y, cellX: NaN, cellY: NaN, inR: 5, outR: 7 });
export function magnetStep(m: Magnet, rawX: number, rawY: number, guides: { x?: number; y?: number }, onCell: (cx: number, cy: number) => void) {
  // alignment guide within 6px widens the magnet on that axis to 6/9
  const nx = guides.x ?? Math.round(rawX / CELL) * CELL, ny = guides.y ?? Math.round(rawY / CELL) * CELL;
  const inR = guides.x != null || guides.y != null ? 6 : m.inR, outR = guides.x != null || guides.y != null ? 9 : m.outR;
  const d = Math.hypot(rawX - nx, rawY - ny);
  if (!m.snapped && d < inR) m.snapped = true; else if (m.snapped && d > outR) m.snapped = false;
  const tx = m.snapped ? nx : rawX, ty = m.snapped ? ny : rawY, ease = m.snapped ? 0.35 : 1;
  m.x += (tx - m.x) * ease; m.y += (ty - m.y) * ease;
  if (m.snapped && (nx !== m.cellX || ny !== m.cellY)) { m.cellX = nx; m.cellY = ny; onCell(nx, ny); }
  return m;
}

export function flipRect(el: HTMLElement, from: DOMRect, to: DOMRect, ms: number, easing: string, reverse = false) {
  const sx = from.width / to.width, sy = from.height / to.height, dx = from.left - to.left, dy = from.top - to.top;
  el.style.willChange = 'transform'; el.style.transformOrigin = '0 0';

  return a.finished.then(() => { a.cancel(); el.style.willChange = ''; el.style.transform = ''; });
}
